📎 Project Name:
# Hasad
📌 Project Overview
Hasad is a mobile application that connects farmers with agricultural suppliers and traders. The app allows farmers to browse and purchase agricultural tools, fertilizers, seeds, and other farming products. It also provides an easy way to communicate with trusted sellers, compare products, and place orders. Hasad aims to simplify the agricultural purchasing process, save farmers time and effort, and support the agricultural community through a user-friendly platform.

🎯 Project Objectives
Connect farmers with trusted agricultural suppliers and traders.
Make purchasing agricultural products easier and faster.
Help farmers compare products and prices.
Improve communication between farmers and sellers.
Save time and effort during the purchasing process.
Support digital transformation in the agricultural sector.
